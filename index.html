Our Project: Book Reseacher App

The Book Researcher is a search tool built for academics. A user types a title, author, or keyword and gets back a list of matching books. Each result shows:

  • a cover image, for quick visual recognition of edition
  • the author(s), which establishes who behind the work
  • the publication year, which shows whether a book is recent or older

Main Goal

Its main purpose is to help academics quickly find the relevant books without getting unrelated results. It helps then explore a topic, find a specific book, and identify the write about the subject.
