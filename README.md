PROJECT DESCRIPTION

Book Researcher is a web-based application designed to assist students, researchers, and readers in finding books for academic and personal use. The application provides a convenient way to explore book-related information and discover useful reading resources. It supports learning and research by making book discovery more accessible.

TECHNOLOGIES USED

• HTML 

• CSS 

• JavaScript 

• openlibrary.org API

PROJECT FILES

• index.html – Main homepage of the website. 

• app.html – Main Book Researcher application page. 

• style.css – Stylesheet for the website's design and layout. 

• script.js – JavaScript file for application functionality. 

• images/ – Folder containing images and other visual assets. 

• README.txt - Information of the Project and Instructions. 

API USED

API Name: openlibrary.org API

API Documentation:
https://openlibrary.org

The openlibrary.org API is used to retrieve book information, including titles, authors, publication details, and book covers, for the Book Researcher web application.

HOW TO RUN THE APP

No special installation is required to access the deployed application.

1. Open a web browser such as Google Chrome or Microsoft Edge.

2. Visit the Book Researcher application using the link below:
https://oblijandacrystal.github.io/Web-Application/app.html

3. Wait for the application to load completely.

4. Explore the available features and interface.

5. Enter a book title, author, or keyword in the search field, if available.

6. Click the search button to find matching books.

7. Browse the displayed results and view the available book information.

IMPORTANT: An internet connection is required to access the deployed website and any online book data services used by the application.
